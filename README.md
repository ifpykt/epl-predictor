# АПЛ Прогноз

Закрытая лига прогнозов на матчи Английской Премьер-лиги для 10 участников.

## Возможности

- вход по логину и паролю без ChatGPT;
- роли администратора и участника;
- участник изменяет только свои прогнозы;
- прогноз автоматически закрывается с началом матча;
- один матч ×2 на каждый тур;
- автоматический подсчёт: точный счёт — 3, разница — 2, исход — 1;
- календарь, результаты и эмблемы команд из football-data.org;
- PostgreSQL и готовый Dockerfile для Timeweb App Platform.

## Раздел «Дела»

В это же приложение встроен закрытый рабочий дашборд по адресу `/dela`:

- канбан и список общих задач;
- приоритеты, статусы, сроки и поиск;
- лента новостей и история изменений;
- добавление задач и новостей через Telegram-бота с подтверждением;
- те же контейнер и PostgreSQL, отдельные таблицы.

Доступ к разделу имеют администратор и логины из `DELA_ALLOWED_LOGINS` (через запятую).
Для бота задайте `TELEGRAM_BOT_TOKEN` и числовые Telegram ID в `TELEGRAM_ALLOWED_IDS`.
Если эти переменные пусты, сайт продолжит работать, а Telegram-бот запускаться не будет.

## Развёртывание в Timeweb

Подробные действия рассчитаны на выполнение вместе с помощником. Короткая схема:

1. Создать PostgreSQL в Timeweb Cloud.
2. Создать приложение в App Platform из этого GitHub-репозитория.
3. Выбрать сборку из `Dockerfile`, порт `3000`.
4. Добавить переменные из `.env.example`.
5. Для `SESSION_SECRET` и `CRON_SECRET` использовать разные длинные случайные строки.
6. Получить бесплатный API-токен на [football-data.org](https://www.football-data.org/client/register) и записать его в `FOOTBALL_DATA_API_KEY`.
7. После первого запуска войти под `ADMIN_LOGIN` / `ADMIN_INITIAL_PASSWORD` и сразу сменить пароль.
8. В панели администратора нажать «Получить календарь и результаты».
9. Подключить `apl.radarmai.ru` к приложению, а в REG.RU добавить DNS-запись, которую покажет Timeweb.

## Автоматические результаты

Создайте в Timeweb задачу по расписанию, которая раз в час выполняет HTTP-запрос:

```text
POST https://apl.radarmai.ru/api/cron/sync
Authorization: Bearer <значение CRON_SECRET>
```

Повторный импорт безопасен: матчи обновляются по идентификатору поставщика, прогнозы не затрагиваются.

## Локальный запуск

```bash
cp .env.example .env
npm install
npm run db:migrate
npm start
```

Для локального PostgreSQL можно использовать любую пустую базу и указать строку подключения в `DATABASE_URL`.
